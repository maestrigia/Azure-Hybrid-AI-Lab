# Azure Hybrid AI Lab

Hands-on labs, scripts, and experiments around Azure Hybrid Cloud, Azure Local, automation, and AI-assisted infrastructure.

## About this repository

This repository contains personal labs, technical experiments, scripts, and architecture examples focused on:

- Azure Hybrid Cloud
- Azure Local
- Cloud Architecture
- PowerShell automation
- AI-assisted infrastructure operations
- Azure AI Foundry
- Retrieval-Augmented Generation (RAG)
- AI agents and agentic workflows

The goal is to document practical learning, build reusable technical examples, and share knowledge with the cloud and AI community.
